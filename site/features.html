01 / FEATURES

Everything you need.
Nothing hidden.

Typing Auto is a focused desktop utility, not a cloud workspace. The controls stay close to the action and the local file stays yours.

01

Snippets that stay local

Every snippet has a name, text, and optional hotkey. They are saved as readable JSON in ~/.typing-auto/snippets.json or %USERPROFILE%\.typing-auto\snippets.json.

LOCAL JSON
02

Typing you can see

Text is sent character by character through the public keyboard abstraction. Newlines and tabs are handled explicitly, with a visible countdown and status line.

OS INPUT
03

A pace that fits

Use characters-per-minute, bounded timing variation, and a countdown to make the interaction comfortable for your field or test fixture.

TIMING
04

Test before targeting

The local test pad lets you verify a snippet, line breaks, and timing without sending input to another application.

SAFE TEST
05

Stop without drama

Press Stop or Escape to interrupt the countdown or the active typing worker. The app does not install a service or create a startup entry.

ESC / STOP
